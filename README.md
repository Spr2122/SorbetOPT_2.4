# СорбентОпт — сайт

Статический сайт на [Astro](https://astro.build). Содержимое (товары, цены, контакты, реквизиты)
хранится в двух файлах и редактируется через приложение **SorbentOpt Manager**:

| Файл | Что внутри |
|---|---|
| `src/data/products.json` | Каталог: товары, цены, фото, SEO, статус «опубликован / черновик» |
| `src/data/settings.json` | Контакты, реквизиты, дата прайса, НДС |

Править эти файлы руками можно, но безопаснее через приложение: оно проверяет данные,
делает резервные копии и показывает, что изменилось с прошлой выкладки. Если в JSON окажется ошибка,
сборка остановится с понятным описанием, а не выложит сломанный сайт.

## Команды

```bash
npm install        # один раз
npm run dev        # разработка: http://localhost:4321
npm run build      # сборка в dist/
npm run preview    # посмотреть собранный сайт
```

Переменные сборки (приложение задаёт их само): `SITE_URL` (по умолчанию `https://sorbentopt.ru`),
`BASE_PATH` (по умолчанию `/`), `PUBLIC_NOINDEX=1` — закрыть копию от поисковиков.

## Как это устроено

* Опубликованные товары попадают в каталог, на главную и в sitemap; **черновики не собираются вообще**.
* Цена хранится числом (`null` = «По запросу»), на сайте форматируется автоматически; цена «от …» в шапке главной
  считается из каталога сама.
* При смене адреса (slug) товара старый адрес сам перенаправляется на новый (`oldSlugs`).
* Форм обратной связи нет, сайт не собирает персональные данные — обращения идут в мессенджеры, по телефону и почте.

Выкладка на сервер описана в [DEPLOY.md](DEPLOY.md).


## Версия 2.1

* **Скачать прайс-лист.** При сборке создаётся `price/sorbentopt-price-list.xlsx` (`src/pages/price/[name].xlsx.ts`, генератор — `src/utils/xlsx.ts`, без сторонних библиотек). Кнопка — компонент `PriceDownload.astro` (главная, каталог, страница товара). Отключается `"priceDownload": false` в `settings.json`.
* **Скрытие контактов.** `"hiddenContacts": ["phone", "max"]` в `settings.json` — контакт не показывается нигде (шапка, подвал, окно связи, раздел «Контакты», политика, разметка поиска, прайс) и не проверяется при сборке. Скрыть все нельзя.
* **Свои тексты шапки и подвала.** `"texts": { … }` в `settings.json` (ключи — в `src/data/site.ts`, `TextKey`). Пусто или нет ключа — стандартный текст.
* Все три поля необязательны; редактирует их SorbentOpt Manager 0.5+.
* **Формулировки о поставке.** Сайт сообщает, что продукция поставляется напрямую с завода по ценам завода (шапка, подвал, блок «Поставка», FAQ, примечания к ценам, политика, прайс для скачивания). Тексты задаются в `src/data/site.ts` (`REPRESENTATIVE_LINE`, `SUPPLY_NOTE`) и в шаблонах страниц; шапку и подвал можно переписать из приложения.


## Редактура коммерческих текстов (октябрь 2026)

* Сайт позиционирует СорбентОпт как помощника в подборе продукции и согласовании заказа, а не как производителя. Договор поставки и оплата — непосредственно производителю; доставку оформляет производитель и рассчитывает отдельно.
* Цены обозначены как цены заводского прайс-листа с НДС, без наценки СорбентОпт и без доставки.
* Удалены неподтверждённые точные показатели химического состава/эффективности и неподтверждённые заявления о применении в медицине и пищевой промышленности. Области применения конкретных позиций всё равно нужно сверить с документами производителя.
* **Перед публикацией обязательно заполнить реальные контакты и реквизиты** в `src/data/settings.json`: сейчас там тестовые значения (`+79991234567`, `yourcompany`, `info@sorbentopt.ru`, `[Фамилия И.О.]`, `[ИНН]`, `[ОГРНИП]`). Не публиковать сайт с этими заглушками.
* В `settings.json` дата прайс-листа сейчас `2026-12-01`, то есть позже даты этой редакции (28.10.2026). Установите фактическую дату документа завода перед публикацией. Также проверьте НДС 22%, диапазон объёмов, цены, упаковку и сезонное условие для марки ГР по актуальному прайс-листу.
* Перечень документов по каждой позиции, маршрут/станцию отгрузки и все технические характеристики необходимо подтвердить у производителя. В этой редакции убраны утверждения о гарантированном наличии документов и универсальной применимости.
* Страница политики обработки данных требует юридической проверки на соответствие фактической работе хостинга, аналитики и внешних каналов связи.
